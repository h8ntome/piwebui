# pi-web — UI / UX audit

Full manual + automated audit of the pi-web browser UI, performed on 2026‑11‑08 against the
working tree at `2e383f7` (+ uncommitted refactor) using headless Chromium (`agent-browser`).

**No application code was modified.** All findings are observations plus recommended fixes.
(Only gitignored build output was regenerated — `packages/client/dist` and
`packages/server/client-dist` — so that the bundle under test matched the audited sources.)

## Issue severity scale

| Level | Meaning |
|---|---|
| **Critical** | Feature broken / data silently missing / flow unusable |
| **High** | Clearly wrong or unusable in common paths; needs fixing before polish claims |
| **Medium** | Visible inconsistency, awkward interaction, misleading state |
| **Low** | Small visual / copy flaw |
| **Nit** | Taste-level, cheap to fix |

Each issue entry lists: ID, severity, location, symptom, repro, expected vs actual, and a
recommended fix. Screenshot names are relative to `screenshots/`.

## Test environment (reproducible)

The audit was run against a throwaway instance so that no real user data or provider quota was
touched:

```bash
# 1. fixture workspace + synthetic agent dir (copy of real pi sessions + crafted edge cases)
/tmp/audit/agent/            # agent-dir: sessions copied from ~/.pi/agent/sessions + fixtures
/tmp/audit/agent/models.json # "Mock Local" provider -> http://127.0.0.1:4712/v1
/tmp/audit/ws, /tmp/audit/edge, /tmp/audit/edge2, /tmp/lightlog   # allowlisted workspaces

# 2. deterministic mock provider (no external calls, zero cost)
PIWEB_MOCK_PORT=4712 npx tsx /tmp/audit/mock.mts

# 3. server under test (fresh client build: npm run build -w @piwebui/client && node scripts/stage-client-dist.mts)
PI_CODING_AGENT_DIR=/tmp/audit/agent \
PIWEB_PI_PACKAGE=$PWD/node_modules/@earendil-works/pi-coding-agent/dist/index.js \
npx tsx packages/server/src/main.ts serve --port 4711 --bind 127.0.0.1 \
     --data-dir /tmp/audit/data --agent-dir /tmp/audit/agent --no-open
```

Fixture session files (markdown torture set, tool-call matrix, error/invalid/RTL/CJK/empty/400-entry
sessions) were generated by `/tmp/audit/gen_fixtures.py` and `/tmp/audit/gen_tools.py`.

Viewports exercised: **1440×900**, **820×1180**, **390×844** (plus programmatic checks at the
900/640 breakpoints). Themes: light, dark, "follow system". Tools used: `agent-browser`
(snapshots, DOM/CSSOM probes, axe-core, Web Vitals, network log, network abort), `curl` against
the REST API, and direct SQLite/JSONL fixture generation.
